## 🌟 現場で学習効果が出る！市販以上の教育設計

1. **【色で当てさせない本格探索】正解もダミーも完全同色のクリスタル球体**
   - 正解オーブ・ダミーオーブ・レーダープロット・HUD照準のカラーを**すべて統一のネオンシアン**に設定。
   - 色を見て当てることができないため、**「実際に近づいて球体の記号を自分の目でしっかり識別する」**という本来の教育的探査プレイを実現しました。

2. **【極太・高コントラスト】抜群に見やすい超鮮明シンボル表示**
   - 濃紺の遮光ベースサークルの上に、**純白の極太線（太さ2〜3倍）**で地図記号や単位を描画。
   - 水中で常にカメラ正面を向くビルボードプレートに加え、**球体の頭上に光る立体ホログラム看板**を搭載。
   - 遠くを泳いでいても「文」「〒」「さすまた」「100cm」などの形がくっきりと読めます。

3. **【答えの解説は正解した後に流れる！】達成感を生む学習フロー**
   - **潜水開始前（指令書）**: お題のミッション（「消防署を探せ！」「火消しの道具がモチーフだ」など）を確認して探求心を高めてから潜航開始。
   - **正解した後**: 正解の球体を回収した瞬間に、**「大正解！【消防署の解説】昔の火消しの道具『さすまた』の形から作られたよ！」という詳細な由来解説と音声読み上げ**が流れ、記憶への定着を図ります。

4. **間違えた時の「比較学習（2枚並び解説）」**
   - ダミー球体に触れてしまった時、単に「不正解」とするのではなく、**「❌ あなたが選んだ記号」と「⭕ 探すべき本物」を横に並べて比較表示**！
   - 「交番は◯の中に✕だけど、警察署は◯がない✕だけだよ！」のように、間違いの理由が一目でわかる解説を提示します。

5. **日本語音声読み上げ (Web Speech API) ＆ 全ルビ（ふりがな）対応**
   - 低学年の児童や漢字が苦手なお子様でも一人で学習可能。
   - 指令書、お題、解説テキストを自然な日本語音声で読み上げます（ON/OFF切替可能）。

6. **本日の深海学習ノート（振り返りレポート）**
   - 全5ステージ制覇後、解いた問題の「記号・名前・由来・注意点」がカード形式でずらりと並ぶ学習達成シートを表示。復習や家庭学習の振り返りに最適です。

## 🕹️ 操作方法

| 操作 | PC (キーボード) | スマホ / タブレット |
|---|---|---|
| 前進 / 後退 | `W` / `S` または `↑` / `↓` | 画面左バーチャルジョイスティック (上下) |
| 左右旋回 | `A` / `D` または `←` / `→` | 画面左バーチャルジョイスティック (左右) |
| 浮上 / 潜航 | `Q` (浮上) / `E` (潜航) | 画面右 `▲` / `▼` ボタン |
| ソナー探知波 | `Space` キー | 画面下 `ソナー探知波` ボタン |
| ターゲット回収 | `F` キー | 画面下 `ターゲット回収` ボタン |
| 視点切替 (3人称/主観) | `V` キー | 画面右上 カメラアイコン |

> **💡 サバイバルテクニック:**
> - 水深0m（水面）まで浮上すると、消費した**酸素(O₂)**が一気に急速充填されます！
> - 敵に見つかったら全速力で海藻（ケルプ）の中やアトランティスの柱の陰に逃げ込むと**「🌿 ステルス隠蔽中」**になり見失わせることができます！
