## 🌟 今回の大幅アップデート内容 (Version 3.0)

### 1. 🗺️ 地図記号＆単位を大幅追加！【合計50種類の圧倒的ボリューム】
小学校社会科・算数科の教科書や中学入試・実力テストに登場する重要記号・単位を完全網羅しました。

- **🗾 地図記号（全30種）**:
  - **初級（イージー）**: 学校(文)、交番(⊗)、郵便局(〒)、病院(十字)、神社(⛩)、寺院(卍)、温泉(♨)、田(田んぼ)、畑(双葉V)、果樹園(丸にヘタ)
  - **中級（ノーマル）**: 警察署(✕)、消防署(さすまた⅄)、市役所(◎)、町村役場(⊙)、工場(歯車⚙)、図書館(開いた本📖)、博物館・美術館(🏛)、針葉樹林(▲)、広葉樹林(🌳)、城跡(石垣)、茶畑(3つの点)
  - **上級（ハード）**: 裁判所(秤の皿)、税務署(そろばん玉◇)、老人ホーム(家の中に杖)、発電所・変電所(歯車と稲妻⚡)、風車(3枚羽根)、官公署(国の役所・丸に星★)、竹林(竹の笹)、重要港(船の錨⚓)、採石場(つるはし⛏)

  - かさ: 1L=10dL, 1L=1000mL, 1dL=100mL, 3500mL=3L 5dL

  - 体積: 1m³=1000L, 1m³=1,000,000cm³

### 2. 🎲 毎回ランダム出題システム（リプレイ性無限大）
- 固定問題ではなく、選択した難易度モードのプールから**毎回ランダムに5問が重複なしで自動選出**されます。
- ダミーの球体も、同ジャンル（地図記号なら他の記号、単位なら他の単位）から**毎回異なる組み合わせでランダム配置**！
- 何度でも飽きずに楽しく復習し、確実な記憶定着を図ることができます。

### 3. 🎯 超高視認性＆色当て防止（真の探索学習）
- **正解もダミーも完全同色のクリスタルシアン**: 色で当てる不正を防ぎ、球体に近づいて記号を自分の目でしっかり確認して見分ける学習性を担保。
- **純白の極太線画 ＋ カメラ正面ビルボード ＋ 頭上立体ホログラム**: 水中を移動しながらでも遠くからくっきりと記号が視認可能。

### 4. 💡 潜水前指令書 ＆ 正解後の納得解説フロー
- 潜水開始前にはミッションの心得を確認。
- 正解の球体を回収した瞬間に、**国土地理院公認の歴史的由来・意味・覚え方のコツ**が画面と日本語音声読み上げ（Web Speech API）で流れます。

## 🕹️ 操作方法

| 操作 | PC (キーボード) | スマホ / タブレット |
|---|---|---|
| 前進 / 後退 | `W` / `S` または `↑` / `↓` | 画面左バーチャルジョイスティック (上下) |
| 左右旋回 | `A` / `D` または `←` / `→` | 画面左バーチャルジョイスティック (左右) |
| 浮上 / 潜航 | `Q` (浮上) / `E` (潜航) | 画面右 `▲` / `▼` ボタン |
| ソナー探知波 | `Space` キー | 画面下 `ソナー探知波` ボタン |
| ターゲット回収 | `F` キー | 画面下 `ターゲット回収` ボタン |
| 視点切替 (3人称/主観) | `V` キー | 画面右上 カメラアイコン |

> **💡 サバイバルテクニック:**
> - 水深0m（水面）まで浮上すると、消費した**酸素(O₂)**が一気に急速充填されます！
> - 敵に見つかったら全速力で海藻（ケルプ）の中やアトランティスの柱の陰に逃げ込むと**「🌿 ステルス隠蔽中」**になり見失わせることができます！
