## 🌟 アプリの特徴・学習内容

1. **リアルタイム3D水族館＆潜水艦シミュレーション (Three.js)**
   - 巨大水槽の中を潜水艦で自由に潜航・浮上・旋回探索。
   - サンゴ礁、巨大ケルプ（海藻）の森、古代アトランティス沈没遺跡、深海発光洞窟、最深部アビスなど全5ステージのバイオーム変化。
   - 潜水艦のデュアル高輝度サーチライト、スクリュー回転、泡パーティクル、水深・速度メーター、グラスコックピット視点切替機能。

2. **小学校の重要学習単元を完全網羅 (全5問・3難易度)**
   - **イージーモード（低学年〜中学年向け）**:
     - 基本の地図記号（学校・郵便局・温泉など）
     - 基本の単位（1m = 100cm、1kg = 1000g など）
     - おとなしい小型ドローン巡回魚
   - **ノーマルモード（中学年〜高学年向け）**:
     - 頻出の地図記号（消防署「さすまた」、市役所「◎」、寺院「卍」など）
     - かさや面積の単位換算（1L = 10dL、1ha = 10,000m² など）
     - 索敵範囲を持つシュモクザメや守護エイがパトロール
   - **ハードモード（高学年・マスター向け）**:
     - 紛らわしい応用記号（老人ホーム、工場「歯車」、針葉樹林「▲」など）
     - 複雑な体積・単位計算（1m³ = 1000L、3500mL = 3L 5dL など）
     - 俊敏に襲いかかる深海アンコウ＆巨大メガロドン！

3. **リアルなステルス（隠密）潜航システム**
   - 敵の魚に見つかると索敵レーダーが赤く光り、けたたましいアラートとともに追尾・突進！
   - 水中に茂る**「海藻（ケルプ）の森」**や**「アトランティスの石柱・神殿の影」**に潜り込むと、**「🌿 ステルス隠蔽中」**となり、敵の索敵レーダーから完全に姿を消すことができます。

4. **Web Audio APIによる完全コード生成サウンド**
   - 外部音声ファイルへの依存ゼロ！
   - 水中アンビエント音、推進エンジン音、ソナー発信音（キィーーン…）、警告サイレン、正解ファンファーレ、被弾衝撃音などをブラウザ上でリアルタイム合成生成。

5. **いつでも学べる「地図記号＆単位 大図鑑」搭載**
   - 国土地理院が定める全記号の正確なベクター描画と由来・意味・覚え方の豆知識を完全収録。
   - 算数の単位（長さ・重さ・かさ・体積・面積）の関係式・換算表をいつでも復習可能。

## 🎮 操作方法

| 操作 | PC (キーボード) | スマホ / タブレット |
|---|---|---|
| 前進 / 後退 | `W` / `S` または `↑` / `↓` | 画面左バーチャルジョイスティック (上下) |
| 左右旋回 | `A` / `D` または `←` / `→` | 画面左バーチャルジョイスティック (左右) |
| 浮上 / 潜航 | `Q` (浮上) / `E` (潜航) | 画面右 `▲` / `▼` ボタン |
| ソナー探知波 | `Space` キー | 画面下 `ソナー波探知` ボタン |
| ターゲット回収 | `F` キー | 画面下 `ターゲット回収` ボタン |
| 視点切替 (3人称/主観) | `V` キー | 画面右上 カメラアイコン |

> **💡 サバイバルテクニック:**
> - 水深0m（水面）まで浮上すると、消費した**酸素(O₂)**が一気に急速充填されます！
> - 敵に見つかったら全速力で海藻の中やアトランティスの柱の陰に逃げ込みましょう！
